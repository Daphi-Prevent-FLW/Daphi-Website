## 2. Final structure and decisions
- **Routes** (`/{lang}/…`, identical slugs): Home `/`, `flw-prevention/`, `partnerships/`, `data/`, `about/`, `resources/`, `acknowledgments/`, for `en` and `he`; `/` is a language entry page (works without JS); `/404.html` is bilingual and `noindex`; `/robots.txt` is generated by `src/pages/robots.txt.ts`. 16 pages were reported by the owner's Cloudflare build log.
- **Architecture**: fully static, no adapter; one config file (`src/config/site.config.mjs`); routes/section ids in `src/config/routes.mjs`; copy only in `src/i18n/{en,he}.ts` (Hebrew type-checked against English); data in `src/data/*.mjs`; build-time validators in `scripts/`.
- **Bilingual and RTL/LTR**: `lang`/`dir` per route; logical CSS properties only (a few symmetric physical shorthands remain, CSS-01); the language switcher maps pages one-to-one and keeps `#fragment`; logos and icons are never mirrored. All Hebrew was written by the model and needs native review.
- **Citations and placeholders**: references and citation instances are separate; identity is the `id`, the displayed number is the registry position; markers work without JS and add a popover with JS; everything not final is a marked placeholder (`[PLACEHOLDER]`, `status: 'placeholder'`, a text badge), one switch hides the badges, `list:placeholders` shows what is left. The site publishes no statistic and no real reference (`check:figures` enforces the former).
- **Sensor section and About timeline**: one shared sensor source (`src/data/sensor.mjs`), information first, funding appeal last (Home and About); timeline in `src/data/timeline.mjs`, one confirmed current milestone, one planned item, three undated placeholders; no date was invented.
- **SEO**: absolute URLs are only emitted when `siteUrl` is set (canonical, hreflang/`x-default`, `og:url`, `og:image` if a raster file exists, sitemap, `Sitemap:` line). No JSON-LD.

## 5. Assumptions and what to adjust at integration
- The existing Daphi repository was never seen; the integration guide lists what to compare, not what is there.
- `x-default` points to the language entry page because no default language was named (SEO-02); `DEFAULT_LANG = 'en'` exists only for the sitemap option.
- Real statistics will trip `check:figures` and the statistic-description digit rule by design; relax them when figures are added.
- `/fonts/*` is cached as immutable but the files are not hashed; rename a font file if it is replaced.
- The CSP allows inline scripts and styles (SEC-01).
