# Acknowledgment pictures (to be supplied)

Put contributors' profile pictures here (square-ish, e.g. `dana-levi.jpg`) and reference them from
`src/data/acknowledgments.mjs` as `picture: 'assets/people/dana-levi.jpg'`. The file is checked at build time:
a missing file simply means no picture (no broken image, no empty circle). Only add pictures the person has agreed to publish.
